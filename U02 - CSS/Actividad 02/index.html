Botones

display: none - El elemento desaparece COMPLETAMENTE como si no existiera.

visibility: hidden - El elemento desaparece VISUALMENTE pero sigue ocupando espacio. en el navegador.

Fijate en el espacio: El botón con display: none desaparece y no deja espacio vacío. El botón con visibility: hidden desaparece pero el espacio sigue ahí (ves un espacio en blanco).
